This is a project that is built upon the data set shared by Youtuber Ken Jee. As the data set's name, the stakeholder is a Youtuber and he wants to know how to grow is channel. 

The analysis is put in the form of a dashboard with select boxes on the left.

Several new analysis includes video output by years, top liked videos, top views videos, etc.
The Aggregate Metrics page show the overview performance of the youtube channel. Specific video analysis available in Individual Video Analysis. Top 10 Analysis is where we can see the most outstanding metrics overall
